== Введение

Данный IP блок реализует модуль прямого доступа к памяти посредством шинного интерфейса AHB-Lite. Кроме того, модуль содержит два отдельных канала, каждый из которых настраивается регистрами контроля и статуса, которые доступны через AXI-Lite интерфейс.

=== Пояснения

Управление работой блока происходит через регистры контроля и статуса. С их помощью устанавливаются адреса источника и назначения каждого из каналов, а также выбор типа транзакции, одиночная или пакетная и вид пакетной транзакции (incrementary burst или wrapping burst).

Каждый из каналов обладает собственным блоком формирования адреса, где генерируется адрес источника и адрес назначения исходя из числа транзакций, а также их типа. Также, в каждом канале находится отдельный блок формирования управляющих сигналов для AHB шины. Данные отправляемые каждым каналом буферизуются в отдельных FIFO.

Выбор канала осуществляется отдельным блоком, реализующий TODO алгортим арбитража.
